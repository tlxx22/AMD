## 文档规则

- Plan：未来准备怎么做；
- Milestone：某一阶段实际做了什么；
- Evidence：机器生成的 patch、清单和原始证据；
- Archive：已经失效、不能继续指导开发的旧方案；
- 每个 M 阶段只有一份 `milestones/Mx_*.md`；
- 阶段完成后冻结，不在后续阶段继续追加；
- 原始训练日志、checkpoint、metrics、manifest 放在 artifacts，不复制进 docs。
